# 数值预测与稀疏历史

预测任务固定输出 24h、48h 整数百分比。AI 提取语义特征，程序计算概率；普通历史、明确期限、预计或条件计划仍分别处理。本次调整只涉及预测任务，不改变一条消息拆分出的并行、链式任务及独立投递。

## 基线

至少三个可用间隔时保留原来的四模型组合。更少时使用 Gamma–Poisson 事件率先验：`α₀=1`、`β₀=10天`。从首个可用完成公告起，`n` 个事件、观察长度 `E` 天得到 `α=1+max(0,n−1)`、`β=10+E`；未来 `h` 天概率为 `1−(β/(β+h))^α`。没有事件时直接使用先验。十天是工程先验，不是个人每周自动刷新的周期，也不是虚构的历史事件。

## 明确期限承诺

完整官方限时 global 承诺使用两条数值路径：严格审计的可比历史满足原有精度门槛时，保留条件兑现估计；其余使用 `promise-prior-1`。未核实、手动卡、条件计划、否定、已完成或已撤回的预告不获得此调整。

平滑模型把承诺看成一条有交付时间分布的可能兑现路径。默认兑现概率先验为 `Beta(4,1)` 的均值 `q=0.8`；条件于兑现，80% 的交付质量均匀分布在预告发布至期限之间，其余20%服从期限后的指数延期分布。默认延期均值3小时、先验质量3，按相同时间精度和提前量的历史已核实完成时间更新，历史样本半衰期90天。每个重置周期只取一条原始预告；改期案例不参与延期长度学习。

设上述交付累计分布为 `D(t)`，当前尚未观察到完成，未来 `h` 小时的承诺兑现概率为：

`c(h) = q × [D(now+h)−D(now)] / [1−q×D(now)]`

与同一时点的普通基线 `b(h)` 组合为 `m(h)=1−[1−b(h)]×[1−c(h)]`。这是显式工程混合模型：承诺交付与背景重置提供两条可能路径，不声称二者已通过独立性验证。两次应用策略从保存的原始基线开始，不能重复抬升概率。期限在24h外、48h内会产生不同窗口概率；逾期后剩余承诺质量连续减少，最终回到背景基线。

已有 `n` 个严格审计的可比窗口、其中 `a(h)` 个发生完成公告时，使用 `p(h)=[a(h)+4×m(h)]/(n+4)` 进行收缩；审计样本充分时转用既有 Wilson 平滑估计。未知和未观察完的案例不计为失败，也不将只抓到的成功案例用作兑现率分母。正结果可用于交付时间学习，不等于已审计的完整兑现率。

以上常量都是可检查的先验参数，不是写死的最终百分比。最终结果随当前期限、已等时间、基线、已核实延期和可比窗口结果变化。详细记录在 `forecast.promisePolicy/promisePrior/promiseHistory/ratePrior`；公开报告只给数值、引用和简短理由。
