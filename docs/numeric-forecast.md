# 数值预测与稀疏历史

策略版本 11。预测任务固定输出 24h、48h 整数百分比。历史时间层始终运行；可选模型仅提取公开发言的数值特征，不直接给概率。一条消息拆出的上香、预测及其他并行或链式任务不变。

## 永久历史与基础曲线

所有已取得的重置时间及官方正文保存在 ledger，只合并，不按日期清理。排序、去重、排除未来事件后构造逐次间隔；banked 和个人周刷新不移动 global 时钟。时间输入包括全部事件 epoch、相邻间隔、最近 12 次记录和间隔、已等待小时/天，以及 UTC 和作者太平洋时区的星期、月内日期、月初/中/末。

至少三个可用间隔时保留四个基础模型，加入强收缩的近期节奏候选，条件模型只使用比当前已等时间更长的间隔。更少时使用 Gamma–Poisson 先验 α₀=1、β₀=10 天；从首个完成起，α=1+max(0,n−1)、β=10+E，p(h)=1−(β/(β+h))^α。零事件仍给先验数值。

日历层在该曲线之上运行：星期、日期、月份阶段和日内时段的事件率向整体率收缩，用双尺度分布修正未来小时风险，再积分得到 24h/48h。完整参数、周期权重和近期节奏见[动态时间层](adaptive-time.md)。这是平滑的时间分布模型，未用小样本拟合任意复杂系数。

## 发言特征与交付模型

六个窗口和官方资料始终有数值记录。AI 可用时一次请求同时返回所有窗口分数及带引用的断言；失败时由本地规则生成相同结构。历史曲线与公式完全相同，只有语言提取器不同。

确定、未消耗的官方 global 决定或有期限承诺才启用交付路径。有效每日 full reset 计划中的 Day N 选定 reset 属于该日交付决定，不是已完成公告；仅有标签时以作者当地当日日终作估计窗口，并标 programme-day，不冒充明确时刻。本人已核实自回复有落地期限时优先用该期限；无官方引用关系不把相邻发言拼接。

当前采用显式工程先验 Beta(19,1)，不是历史兑现 19 次。近期五窗对重叠证据归一化，已完成之前的引用不贡献下一次机会。语义强度 s 只折减一次先验赔率：q=19s/(1+19s)。普通暗示、一般事故或条件长期计划不凭少量案例任意加分。公式及每窗贡献见[固定设计](dimensional-forecast.md#概率公式和-day-标签)。

条件于交付，80% 质量均匀分布于发布至期限，其余20%为期限后的指数尾部，均值3小时。设 CDF 为 D(t)，未观察到完成时，未来 h 小时剩余质量：

`d(h)=q×[D(now+h)−D(now)]/[1−q×D(now)]`

与原始时间基线 b(h) 合成：`p(h)=1−[1−b(h)]×[1−d(h)]`。这是假设明确的工程混合模型，不声称两条路径已经通过独立性或校准验证。不是固定给90%，也不把上一次已抬高的预测当作新基线；逾期会连续回落。

严格审计的历史可比窗口满足原有门槛时，优先采用条件兑现估计，跳过上述先验路径。没有完整覆盖的窗口不当失败，也不能只拿抓到的成功案例估计兑现率；具体审计标准见[结构化特征](structured-features.md#历史承诺兑现估计)。旧 promise-prior-1 计算记录仅作诊断，由 dimensional-delivery-1 取代，不再叠加。

## 完成之后

先处理完成事实，再计算概率：移动等待起点、消耗此前承诺和暗示，重新计算原始时间曲线。即使旧帖仍在六个窗口里，仍不能恢复旧加权。完成后若又有新的独立承诺，按新发布时间处理；没有新承诺则回到新周期的历史与日历基线。

`forecast.temporal` 保存时间输入、桶计数、暴露量和风险曲线；`forecast.dimensions` 保存七个窗口的分数、引用、已消耗比例、权重、贡献和最终交付质量。诊断与实际报告账本保存相同数据，公开消息保持概率、引用和简短理由，并固定增加一行有条件的重置卡建议。
