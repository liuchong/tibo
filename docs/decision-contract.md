# 算法与证据契约

## 独立报告策略 2

报告区分三件事：公开完成公告是否出现、未来 24/48h 的历史估计、当前的明确承诺/暗示。个人账户额度是否生效始终 unknown。banked 是需要手动兑换的卡，发卡不移动 global 时钟。概率为整数，范围 0–100，48h≥24h。

保持报告可读的标题、结论、客观数据、概率推导、未核实项和执行摘要；新增信号判断、模型验证。UTC 时间与北京时间标题各自明确。原文保留英文。没有核实的数据不写“无”。此前的外部 skill 是需求参考，不是程序的规范或运行依赖。

## 历史估计

先按公告时间排序、去重、排除未来记录，根据可用原文纠正类型。识别出的未来承诺不能记为完成重置。只使用 global 邻接间隔 D，当前已等时间 t。

- 近期率：最近 12 个可用间隔，λ=n/ΣD，p(h)=1−exp(−λh)。当前未完成等待不作为一个完整间隔，等待更久不会令此模型人为变成“该重置了”。
- 衰减率：每个间隔权重 w=2^(−距间隔结束天数/90)，λ=Σw/Σ(wD)。
- 条件模型：只选 D>t；a=满足 D≤t+h 的间隔数，n=剩余样本数，p=(a+4×近期率概率)/(n+4)。零条件样本回到近期率，不造 100% 或进行 0/0 计算。

间隔任一端涉及站点观测则排除该间隔，保留原始历史与排除计数；不跳过该事件再拼接新间隔。少于 3 个可用间隔时不输出概率，状态仍可查询。

从已有 8 个完成间隔后开始逐日回放：每个时点只使用此前结束的间隔，标签为该时点后严格 24/48h 内是否有下一条 global 记录。只有完整 48h 观察窗口才计分。Brier=平均(p−y)^2。回放窗口彼此相关，历史补录可能改变成绩，不能声称还原了当年实际可取得的完整信息。

≥30 个回放时点时，权重 ∝ 1/(0.05+平均 24h/48h Brier)，否则等权。0.05 防止一个偶然极小误差支配结果。12 个近期样本、90 天半衰期、4 个平滑样本和 30 个启动时点是首版固定超参数，没有经过广泛搜索，也没有证明最优。模型的微小回放差异不代表显著优势。

## 实际预测经验

联网 forecast 在生成报告时保存本次窗口、各模型概率和信号，最多保留 1,000 条；窗口间隔≥48h，不回填历史预测。离线和快照复现不作为实测预测保存。

48h 窗口结束再等待 10 分钟入库宽限后，根据本地公告记录标记 24/48h 标签。累计至少 30 个窗口的模型成绩才用于权重；未来权重计算使用回放误差与实测误差各 50%，实测不足则只用回放。未记录到事件表示“本地记录未见”，不能证明全球没有事件，completeCoverage 始终为 false。当前概率置信度保持低，明确承诺的证据强度单列。

## 公告信号

支持对象明确且带 today/tomorrow、am/pm、PST/PDT/PT 的时间承诺，tomorrow 按旧金山日期；PST=UTC−8，PDT=UTC−7，PT 使用 IANA 夏令时。无法解析的时间不伪造目标。

前次完成 global 消耗此前信号；banked 只有明确关联到承诺才能消耗它。对象、时间、出处、是否兑现和独立事故信息用于状态与跟进；没有足够校准样本时不添加固定概率奖励或惩罚。明确承诺不会自动变成 90% 的统计结论。

## 数据与运行边界

所有业务由 Eliscript 实现，依赖 Bun 内置 HTTP、文件、WebSocket 和标准宿主能力，不加载第三方运行库。核心无需模型；可选 AI 通过官方 HTTP API 调用 deepseek-flash。存档用于历史发现，X 官方 oEmbed 用于核实已知帖子；这不等于持续观察全部帖子。RSS 与状态事故不是全网新闻，也不能证明未来补偿。

## 可选 AI

signals 只补充带逐字引用的语义解释，forecast 返回概率建议，brief 生成辅助摘要和后续观察事项。分别开关，AI 不添加历史事件、不改写 global 时钟、不改变状态的证据等级。摘要和分类仍可能错，按模型推断呈现。

forecast 改变数值必须引用近48h、上次global之后的重置或事故相关原文。默认最终 p=0.8×自有算法+0.2×AI，AI 权重配置范围0..0.35；按整数输出，48h≥24h。引用、格式和窗口约束不是语义正确性证明；结果仍未校准。AI失败则完整保留自有算法数值。前瞻经验同时保存基线、AI建议与最终结果；至少30个AI窗口后，仅当AI误差更差才下调权重，不凭小样本放大权重。

密钥只存在本地配置/进程内存。AI只收到公开证据和聚合统计，不收到密钥、飞书配置或聊天。认证/余额/限流/网络影响供应商级暂停，参数或输出错误影响单项功能。冷却状态跨重启保留；冷却结束的请求在独占锁下试探，成功复位。没有即时重试，失败原因使用固定脱敏文本，不记录供应商错误体或思考内容。

网页只按数据解析，不执行脚本。来源超时、结构缺失、历史截断、身份不符和空正文要显式失败或降级。历史持久化后可离线运行，首次启动缺数据仍须失败或返回 unknown。

飞书在独立层内直接调用 API 并实现长连接二进制协议。群白名单、真实 bot mention、用户身份及消息时效共同约束查询；投递前落账，未知发送结果不自动重试。协议模拟与本地 API 替身不是线上收发证据。
