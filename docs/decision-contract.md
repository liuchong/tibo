# 判断算法与证据约定

Tibo 预测的是未来 24h / 48h 内是否出现新的 global 完成公告，不查询个人账户额度。本文描述当前实现，固定超参数是工程选择，尚未证明最优。算法策略为 10；统计基线来自自有模型，明确限时的官方承诺在可比、经过审计的历史样本充分时使用条件兑现估计，否则使用显式先验的平滑数值估计，AI 仅提取和解释特征，不直接给正式概率，完整推导保留在本地 JSON 与诊断中。公开格式以 [预测报告约定](forecast-report.md) 为准。

六个发言窗口、日历数值、一次 AI 与本地降级共用公式见[多维设计](dimensional-forecast.md)。当前结构化提取、状态、缓存、降级与产物门槛见 [实现约定](structured-features.md)。[模型设计](feature-forecast-design.md)保留后续拟合与验证方法；当前没有启用经过校准的特征权重。[历史关联研究](research/message-reset-study-2026-10-12.md)记录有限样本的实际试验。

## 事件与时间

**global** 是统一完成公告；**banked** 是需要手动使用的额度卡。banked 不移动 global 等待时钟，也不能直接当作完成重置。未来承诺、二选一计划和发布里程碑必须与完成事件区分。

**个人每周自动刷新**是第三种事件，不是额外强行 global。7 天到期不登记为 global，不重启 global 等待时钟，不结算 global 预测为命中，也不意味着未来 24h / 48h global 概率变成 100%。原文、摘要或事件类型表明只是自动每周刷新时，即使发现记录误分类为 global，也会排除。

### 重置时钟与 7 天参考

`cycle` 保存上次 global 时间、已过小时、公告是否在过去 24h 内、上次 global 加 7 天的参考时刻及剩余天数。只有完成措辞已确认且不是单纯观测时，才显示“刚重置过”和参考倒计时；满 7 天后显示参考已过，不推断又发生了 global。

参考倒计时不是个人到期时间。程序没有个人额度或下一次自动刷新数据，`accountNextAutomaticAt` 为 null，账户是否生效为 unknown。个人周期起点、手动使用卡或购买重置会影响日期，应看自己的额度页面。[官方付费重置说明](https://help.openai.com/en/articles/20001507-paid-weekly-work-and-codex-rate-limit-resets)明确说明该操作后的下一周周期从首次请求开始；[额度卡说明](https://help.openai.com/en/articles/20001498-how-banked-codex-resets-work)也说明使用卡会改变每周日期。这不能外推为所有账户统一在公告后第 7 天刷新。

统计模型使用实际已等时间；已完成新 global 后，从新起点计算条件剩余等待，旧暗示不再加权。日志还保留已等不足 24h、1..7 天、超过 7 天及未知时钟等背景；旧分组概率调整已停用，不能作为新特征训练标签。7 天只是经验分组边界和解释参考，不是额外奖励或强行重置截止日。AI 也收到这些字段与约束；不会在已有条件模型外重复扣“刚重置”的固定分数。

证据快照有独立 now，联网采集先取当前 UTC。公告去重、排序并排除未来事件，能取得原文时核对完成措辞和类型。最新 global 的时刻是等待起点 t；个人账户是否生效始终未知。

来源分为官方原文、本地保留的旧原文和分类/观测。联网帖子采集只请求 X 官方公开主页、官方单帖页面与官方 oEmbed；状态页、官方 RSS 提供背景资料。主页同时支持带 tweetText/time 的结构和服务器渲染的正文结构，后者通过帖子 ID 解码发布时间。引用文章与父帖正文分开，不把被引用人的话当作 Tibo 自己的声明；不执行页面脚本。

官方嵌入正文可能截断。此时请求固定作者的官方单帖页面，核对作者、帖子 ID、未截断全文和摘录前缀后补全，仍是原文等级；失败则保留截断标记，不猜测完成句。截断帖不创建新的完成事件。新发现的原帖及完成公告累计进本地 ledger，不覆盖用户档案或已有历史。

公开页面不保证涵盖所有回复、删帖或历史。相关原帖详情页会补充有限的作者自回复，见 [资料缓存](evidence-cache.md)。主页获取成功不代表完整历史已更新：historyFresh 只有来源明确提供完整历史覆盖时才成立，当前公开页面路径不会设置它。因此可记录已经核实的重置命中，不能用未见帖子自动结算为负结果。无历史的新安装使用显式稀疏事件率先验，仍正常输出数值；合格的明确交付决定再加入条件交付模型。原有安装继续使用已积累的本地历史，并保留其核实等级。

## 历史样本

先构造相邻 global 的完成间隔 D，不把当前尚未结束的等待当作已完成样本。间隔任意一端是站点观测则排除该间隔，不跳过事件后拼接一个人为长间隔。至少三个可用的非观测间隔使用四个基础候选加近期节奏候选组合，更少则使用稀疏事件率先验。

本地 JSON 中的历史、全样本条件计数可以含站点观测；模型明确排除它们。因此计数不一定等于模型可用样本量，模型另列排除数。仅有站点观测的最新记录仍保留其证据等级，不能把它当作已核实账户重置。

## 四个基础模型

以下 D、t、h 均以天为单位；24h 对应 h=1，48h 对应 h=2，p 在公式中为 0..1。

| 模型 | 计算 | 作用与局限 |
| --- | --- | --- |
| recent-rate | 最近最多 12 个可用间隔；λ=n/ΣD；p(h)=1−exp(−λh) | 反映近期事件率；长时间等待不会自动变成“该重置了” |
| decayed-rate | w=2^(−距间隔结束天数/90)；λ=Σw/Σ(wD)；p(h)=1−exp(−λh) | 旧经验逐步降权，仍假设未来可用历史率近似 |
| decayed-conditional | 在 D>t 的条件样本中按同样的 90 天半衰期加权，用 decayed-rate 和 4 个先验样本平滑 | 结合已等时间与新旧经验；条件样本稀疏时回退衰减事件率 |
| conditional | 只选 D>t，a=满足 D≤t+h 的数量；p=(a+4×recent-rate 的 p)/(n+4) | 使用已经等待 t 的条件样本，以 4 个先验样本平滑小样本 |

条件窗口严格为 t+24h / t+48h，分母只包含比当前等待更长的历史间隔；上边界包含等号。没有条件样本时回到 recent-rate，不产生 0/0 或虚构 100%。

四个模型保持原公式；另加入强收缩的 `adaptive-rate`，从14/45/90天尺度和当前未结束等待估计近期节奏。五候选组合保持0..100与p48≥p24，不另乘固定提速奖励。日历层保留星期/日期/阶段并增加日内时段。完整公式及参数见[动态时间层](adaptive-time.md)。

## 回放与自适应权重

从已有8个间隔后按时间回放，只用预测当时的历史。逐时点误差保留诊断，组合权重改用逐重置周期平均Brier，再结合45天衰减近期周期误差。达到8个回放周期或某候选30个前瞻窗口时，误差偏好与均衡权重按有效支持n/(n+20)混合；不足则均衡。重复时点不增加有效周期数，回放与前瞻仍区分，不能当作已校准准确率。

## 实际预测经验

联网 forecast 保存真实预测时刻、各模型、最终概率与信号；最多 1000 条，预测窗口间隔至少 48h，不回填历史。另保存计划上下文、证据选择和 AI 实际权重，便于区分模型表现变化与证据缺失。离线和快照复现不计入前瞻经验。

48h 窗口结束后再等 10 分钟，在下一次联网预测中用已收集公告给旧窗口标记结果。y24/y48 的事件区间为预测时刻之后、对应上边界之内。窗口内含完成原文未确认或单纯观测事件时，暂不结算。至少30个已结算模型窗口后，该候选误差使用周期回放和实际预测误差各50%；回放不足时其份额采用默认误差0.25，学习份额仍向均衡收缩。

标签依据是 observed-ledger，completeCoverage 始终 false。“本地未见公告”不能证明全球没有发生，遗漏会影响经验成绩。当前概率置信度维持低，明确承诺的证据强度另列。历史原文核实、模型拟合、自适应和真实世界覆盖是不同问题。采集失败、只有缓存历史的快照不会把已到期窗口结算成“没发生重置”；只有明确覆盖相应历史窗口后才结算负结果。

### 每份实际报告的复盘

`forecast-journal.json` 另存最近 400 份实际联网数值报告，包含原始时刻、概率、通道与策略版本。同一通道、同一时刻只登记一次。升级时只补录仍在本地的上一份定点报告，要求 report、evidence、diagnostics 的时刻一致，且概率一致；明确标为 saved-report。绝不把重跑、离线或快照计算伪装成过去真实预测。

交互预测从原采集时间起共享两分钟结果，同时到达的请求只生成一次。缓存命中保留原时刻，不新增一次预测或训练样本，首次生成登记生成通道；各请求的成功投递和本地报告仍分别保存。已知新证据、经验、相关配置/AI 冷却以及管理员清理使缓存失效。定点、离线和指定快照计算跳过此缓存，定点结果仍按原有槽位生成一次。

`review` / `复盘` 展示最近 6 份报告。完成公告落入严格窗口时，可立即登记正结果；这只是报告复盘。负结果要窗口结束加 10 分钟、历史采集成功且窗口内无疑似事件。源临时失效不抹掉已确认的结果；新补录事件可以修正先前未见公告的标签。个人每周刷新不计入。

复盘窗口互相重叠，不进入模型权重或同类信号频率训练。AI 最多收到 3 个不同重置事件的真实报告案例，每个事件只一例，并附完成文字；用来避免“当天已经更新就不可能 reset”等解释错误，不作为固定概率奖励。独立训练仍只使用原有不重叠 48h 样本，且等待整个窗口结束，不提前只学习已经命中的样本。一轮低估不能证明另一组概率长期更准。

## 承诺、事故与催化

规则识别对象、时间、承诺/完成与条件计划。支持带 today/tomorrow、am/pm、PST/PDT/PT 的明确时间；tomorrow 按旧金山日期，PST=UTC−8、PDT=UTC−7，PT 根据该日期的 IANA 夏令时换算。不能解析时不编造目标时刻。

完成 global 消耗此前相关信号；banked 是否兑现承诺要检查明确关联，不能把所有 reset 措辞或发布都自动看作 global。`either improvement or reset` 是条件计划，不能推成每天必重置；`updates or a reset` 也按条件计划识别。出现 `Or both` 时，更新和重置可以同日发生。事故已修复、部分账户问题和新补偿承诺也要区分。

### 完成确认与旧预告失效

完成帖可能省略对象，通过官方引用或自回复指向此前预告。保留正文与引用关系为不同字段；从官方页面惰性读取已知原帖的关系，最多沿三层同作者、已核实且按时间先后的关系补齐重置对象。只有可核实的 global 对象与完成态同时成立，才更新完成时钟；普通“done”、相邻帖子、其他作者引用、条件计划、banked 或个人刷新不够。

完成事件先进入统一证据和历史，再计算本次预测：完成时刻之前的一次性承诺、暗示与时间预期标记为已消耗，不能继续使用原承诺概率；新的完成之后发出的新预告仍可独立生效。持续计划只保留背景。概率由完成后的等待时间重新计算，不固定设为零。新事件或引用关系使共享预测缓存失效，状态查询、AI 特征和完成通知使用同一事实。

此前完成确认修复验收：

- [x] 核实官方完成帖及其引用链，保留独立正文，修复永久原文复用时关系遗漏。
- [x] 在统一事件层处理完成确认，验证旧信号失效、新信号保留与无 AI 降级。
- [x] 回归共享缓存、状态查询及独立完成通知，实际 CLI 对比修复前后结果。
- [x] 更新文档，完整回归 411 项通过；实际联网 CLI 验证 AI 开启与关闭均识别本次完成。

交付按 [安装与运维](operations.md#更新与重装) 签名提交、推送并重装两个服务，保留已有数据和通知去重记录。

自有模型把信号与历史概率分开展示：没有足够校准数据时，不添加固定的“承诺 +X%”“banked −Y%”奖励/惩罚，也不直接套用 90%。官方事故记录证明事故，不能证明将发重置补偿。

### 有期限的计划与上下文选取

近 48h 不是所有证据的有效期。`over/for the next N days`、`each/every day` 与更新或 reset 的条件表述同时出现时，规则保留声明期限内的计划；当前 N 支持 1..90 的阿拉伯数字。期限按声明时刻加 N×24h 计算，只用于保留背景，不是某次 reset 的截止时间，也不据此推定具体承诺日的起止。其他无法识别的表述仍按普通近 48h 原帖处理，不假装已理解全部自然语言。

`Day 2.1` 至 `Day 2.4` 归为同一个已见 Day 标签，优先选择 roundup；最多保留最近两个已见日的代表帖。“tomorrow for Day 3”等前瞻日标签不登记为已发生进展。未看到 reset、只看到更新、未取得投票内容，都不能登记为确定的负结果。当前不拟合“每天选择 reset 的比例”；两天更新不足以识别日概率，而且两者可能并存。`Vote`、`To calibrate` 等缺少父帖的短回复不推定含义。

采集核实按优先级限制单轮网络候选，已存完整原文不重复请求。预测另取 ledger 全部已存正文，按六个窗口一次评分，不能把八帖核实预算当作模型输入上限。各窗成员、数量、分数和实际贡献保留本地诊断。

后续 global 消耗计划相关的一次性线索；声明期限和已见 Day 标签继续保留，有效长期计划仍可作为结构化状态，而不是再次累计旧暗示。新原帖可重新提供未消耗线索。banked 不移动时钟，也不自动结束整个长期计划。

## 同类信号经验与信息降级

新特征记录与旧经验分开，保存真实计算和首次特征可用时间、周期、来源质量及未知状态。旧同类信号频率融合已从正式路径移除，不能从重叠报告或未审计的负标签学习新权重。逐帖失败回退规则；没有完整消息和事件覆盖不能训练。门槛与当前无特征模型的状态见 [结构化特征](structured-features.md)。

| 信息情况 | 实际路径 |
| --- | --- |
| 历史与完成原文可用 | 四个基础候选及近期节奏按周期/近期/前瞻误差收缩加权 |
| 最新等待起点只有分类或观测，未核实完成原文 | 停用两个条件等待候选，保留两个事件率候选；不把疑似时间当确定时钟 |
| 原帖发现、状态页或新闻源失败 | 保留本地证据与其日期，分别标缺失；不会等同于“无信号” |
| 搜索失败或未取得官方原页 | 原帖、状态页、RSS 与历史仍能工作；搜索摘要不作事实 |
| AI 未开启、失败、冷却或复核不通过 | 使用可用的自有算法和规则信号，其他独立任务按各自状态继续 |
| 可选预测经验文件损坏或记账锁被占用 | 保留当前预测，不覆盖损坏文件；标记经验暂不可用，继续历史算法 |
| 少于 3 个可用历史间隔 | 使用平滑事件率，仍正常输出两个概率；有效承诺继续参与数值判断 |

本地 JSON 与 diagnostics 记录信息情况和运行延迟，公开预测只保留影响判断的必要描述。发现、正文补全和原文核实均使用固定官方地址；页面失败时降级到带原日期与等级的本地证据，不请求其他预测服务。oEmbed 能重新核实已知链接，但不能发现未知的新帖子。

## 结构化特征与风险计算

AI 输出有限的断言类型、对象、范围、时间词和原文引用；程序核对语义、解析 UTC、管理有效期与兑现。没有 AI、缓存无效或提取失败时回退规则，不能把 unknown 当零。AI 不直接设置概率、模型参数或完成事件。

时间预期独立于明确承诺：AI 按原文区分预计、希望/打算、可能、条件和否定，保留逐字时间词；程序只将明写数字和时区的窗口解析成时钟，不将“明天/很快”自动变成截止时间。新的 `timingExpectation` 候选仅在有合格模型时调整对应六小时风险段。当前没有满足门槛的模型，因此这一维度进入证据、理由和前瞻记录，不以固定加分冒充历史经验。详情见 [语义化时间预期](structured-features.md#语义化时间预期)。

历史四模型形成任意小时窗口的累积概率，再由经过审计、匹配当前信息质量的模型产物调整 6h 风险，累计得到 24h / 48h。零系数返回基线；无产物、少于 30 个审计周期、特征支持不足、时间留出未通过、时钟不可靠或所需特征未知，均不进行拟合特征调整。当前没有经过验证的产物。

完整官方原文明确 global 对象与可解析期限时，按历史承诺在相同等待阶段的完成情况估计，不设固定概率下限。官方核实的自回复可以从父帖和仍有效的 full reset 计划补齐范围，不能凭相邻时间拼帖；明写数字的相对小时窗口按回复发布时间起算。`by EOD PST/PDT/PT` 解析为对应发帖当地日期结束的上限；没有时区的 EOD 仍未解析。重复预告按周期合并，撤回或兑现停止当前承诺调整。严格审计历史达到至少12个可比周期且两个95% Wilson区间宽度均不超过40个百分点时，使用原有条件兑现估计；其余情况使用显式先验、期限分布、已等时间、核实延期及已审计窗口的平滑数值估计。逾期后剩余兑现质量连续衰减，不在六小时处硬切换，也不以“高”或“待确认”替代百分比。原始基线和应用记录保留在 `forecast.promisePolicy/promisePrior/promiseHistory`。公式和参数见 [数值预测](numeric-forecast.md)，结构化路径见 [结构化特征](structured-features.md#历史承诺兑现估计)。

`forecast`、`review` API 任务及默认 20% AI 融合已停用。资料分析和摘要仍是独立可选功能，但只解释事实，不更改数值。完整公式、后续拟合方法和验证要求见 [模型设计](feature-forecast-design.md)，已接入路径见 [结构化特征](structured-features.md)。

## 报告与公开结果

CLI forecast、聊天查询、MCP 和定点推送共用三个固定区块：概率、参考消息、判断理由。参考消息最多四条，Tibo 原帖优先，只补充已经独立核实、时间和原始链接准确且直接相关的官方资料或官方账户原帖；其他来源不凑数。理由最多两句，不列算法、采集或 AI 状态。完整证据、历史基线、结构化特征和特征模型应用情况保留在 `--json` 与诊断中。UTC用于存储比较，报告和定点遵循服务配置的IANA时区。模板、筛选和降级约定见 [预测报告格式](forecast-report.md)。

没有抓到的信息写未核实，不能简单写无。趋势按各报告通道的上一份概率比较，不混入未来时刻报告；共享定点报告使用 schedule 通道，互动查询保持自己的通道。概率不是预言，不用于提供购买或囤额度建议。
